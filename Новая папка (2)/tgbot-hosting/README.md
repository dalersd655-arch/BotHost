# Windows: установка одной командой

1. Установите **Docker Desktop** и запустите его (один раз).
2. Распакуйте архив так, чтобы получилась папка `C:\tgbot-hosting` (ПКМ → «Извлечь всё…» → путь `C:\`).
3. Нажмите **Win+R**, вставьте и нажмите Enter:

```
powershell -NoProfile -ExecutionPolicy Bypass -File C:\tgbot-hosting\setup.ps1
```

Скрипт спросит токен, канал и ваш Telegram ID, проверит их, запустит всё и откроет сайт.
Либо просто дважды кликните `start.bat`. Остановка: `stop.bat`.

# Telegram Bot Hosting (MVP)

## ⚡ Быстрый тест (5 минут, без домена)
Нужен только **Docker Desktop** (Windows/Mac) или Docker на Linux.

1. В @BotFather: создайте бота-привратника (или используйте существующий) и **второй бот для теста**.
2. Создайте канал и добавьте бота-привратника **администратором** в канал.
3. Откройте файл `.env` и заполните 5 строк сверху (токен, username бота, канал, ссылка на канал, ваш Telegram ID из @userinfobot).
4. В папке проекта: `docker compose up -d --build`
5. Откройте **http://localhost:8000** → введите свой Telegram ID → «Войти».
   (Вы должны быть подписаны на канал, иначе вход закрыт — так и задумано.)
6. «Добавить бота» → название, токен **второго** бота, файл `test-bot.zip` → бот соберётся и запустится. Напишите ему в Telegram.
7. Напишите привратнику `/start` — появится меню со статусом подписки.

Логи сервисов: `docker compose logs -f panel gate`. Остановить: `docker compose down`.

### Открыть с телефона / получить https-ссылку
`docker compose --profile tunnel up -d tunnel` затем `docker compose logs tunnel | grep trycloudflare` — получите временный адрес.
Впишите его в `PANEL_URL`, выполните `docker compose up -d`. Кнопка «Открыть сайт» в боте появится сама (Telegram не принимает localhost).
Для входа через кнопку Telegram (вместо Telegram ID): `/setdomain` в BotFather + `DEV_MODE=0`.

### Боевой запуск
`DEV_MODE=0`, `COOKIE_SECURE=1`, `PANEL_URL=https://ваш-домен`, HTTPS через Caddy/nginx, `/setdomain` в BotFather.
Ключи шифрования генерируются автоматически и хранятся в `data/.keys.json` — **делайте его бэкап**.
⚠️ `DEV_MODE=1` позволяет войти под любым ID — никогда не включайте на публичном сервере.

Бесплатный хостинг Telegram-ботов с доступом по подписке на канал.
Стек: FastAPI · aiogram · PostgreSQL · Docker.

## Запуск
1. `cp .env.example .env` и заполните значения (в т.ч. `FERNET_KEY`).
2. В @BotFather для бота-привратника: `/setdomain` → домен панели (нужен HTTPS).
3. Добавьте бота-привратника **администратором в канал** — иначе `getChatMember` не работает.
4. `docker compose up -d --build`
5. Поставьте перед панелью nginx/Caddy с HTTPS (порт 127.0.0.1:8000).

## Формат проекта пользователя
ZIP с `main.py` в корне и (опционально) `requirements.txt`. Токен читается из `os.environ["BOT_TOKEN"]`.

## Что реализовано
- /start, проверка подписки, кнопки «Подписаться» / «Проверить подписку»
- Вход через Telegram Login Widget (подпись проверяется на сервере)
- Загрузка zip (лимит размера, защита от path traversal / симлинков / zip-бомб)
- Отдельный Docker-контейнер на бота: лимиты RAM/CPU/PIDs, non-root, read-only FS, `cap_drop=ALL`,
  `no-new-privileges`, изолированная сеть без доступа к БД, авто-рестарт при падении
- Запуск / остановка / перезапуск / логи / удаление
- Токены шифруются (Fernet), маскируются в логах, не отдаются API
- Лимит ботов на пользователя, журнал действий
- Перепроверка подписки (при входе и раз в 10 мин), остановка ботов после отписки
- Админ-API: `/api/admin/{stats,users,logs}`, блокировка, изменение лимитов

## Ограничения MVP / что делать дальше
- Админ-панель пока только API (UI не сделан).
- Нет лимита диска и сетевого трафика; для недоверенного кода добавьте gVisor/Sysbox
  и egress-фильтрацию (защита от майнинга/спама).
- Панель монтирует `docker.sock` (= root на хосте) — для продакшена используйте socket-proxy или rootless Docker.
- Нет автотестов, миграций (Alembic) и бэкапов БД.
