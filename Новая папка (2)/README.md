# 🚀 Telegram Bot Hosting

Полноценный сервис облачного хостинга Telegram-ботов с единым веб-интерфейсом, проверкой подписки на канал, изоляцией в Docker и админ-панелью.

---

## 🌟 Основные возможности

1. **Единый сервис (Один проект)**:
   - Бот и веб-сервер работают в едином асинхронном процессе `main.py` без разделения на две несовместимые программы.
2. **Telegram-бот с меню-бургером**:
   - Красивое бургер-меню команд (`/start`, `/panel`, `/bots`, `/help`).
   - Кнопка **«🚀 Мой хостинг»** с мгновенной генерацией безопасной ссылки авторизации.
3. **Обязательная проверка подписки на https://t.me/AstrixStudio**:
   - При первом запуске и при каждом действии проверяется наличие пользователя в канале `@AstrixStudio`.
   - Если пользователь не подписан — показываются кнопки:
     - `📢 Подписаться на Astrix Studio`
     - `✅ Проверить подписку`
   - **Автоматическая блокировка при отписке**: фоновый монитор отслеживает отписки и автоматически останавливает активных ботов пользователя, блокируя доступ к панели.
4. **Веб-панель управления хостингом**:
   - Просмотр всех своих ботов и их статусов (`RUNNING`, `STOPPED`, `ERROR`, `STARTING`).
   - Добавление бота с указанием токена BotFather.
   - Запуск (🚀), Остановка (⏹), Перезапуск (🔄).
   - Живой просмотр логов в реальном времени прямо в браузере.
   - Загрузка своих файлов проекта и архивов ZIP.
5. **Изоляция и Docker**:
   - Каждый бот изолирован в отдельной директории `data/bots/{user_id}/{bot_id}/`.
   - Запуск в Docker-контейнере с ограничением ресурсов (CPU, RAM).
   - Умный fallback: если на машине не запущен Docker Desktop, система автоматически запускает бота в режиме изолированного процесса, не прерывая работу сервиса.
6. **Админ-панель (`/admin`)**:
   - Список всех пользователей системы.
   - Управление блокировками (Бан / Разбан).
   - Изменение персональных лимитов количества ботов.
   - Просмотр всех запущенных ботов и системных логов.

## 📁 Структура проекта

```
.
├── main.py                     # Главная точка входа (запуск бота + веб-панели + монитора)
├── bot.py                      # Telegram-бот (aiogram 3, меню-бургер, проверка @AstrixStudio)
├── web.py                      # Веб-сервер aiohttp + API управления ботами + админка
├── config.py                   # Конфигурация сервиса
├── database.py                 # База данных SQLite (пользователи, боты, токены, логи)
├── docker_manager.py           # Менеджер изоляции (Docker контейнеры + Process isolation)
├── requirements.txt            # Зависимости Python
├── .env.example                # Пример настроек окружения
├── test_scenarios.py           # Автоматические тесты сценариев
├── static/                     # Стили и клиентские скрипты
│   ├── style.css               # Современная темная тема и анимации
│   └── app.js                  # Логика SPA панели, живые логи и управление
└── templates/                  # Шаблоны страниц
    ├── index.html              # Главная панель управления
    ├── admin.html              # Админ-панель
    ├── blocked.html            # Экран блокировки при отсутствии подписки
    ├── login_info.html         # Инструкция по авторизации
    └── default_bot/            # Базовый шаблон нового бота (aiogram 3 эхо-бот)
        ├── main.py
        └── requirements.txt
```

## ⚡ Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env` (или создайте `.env`):
```env
BOT_TOKEN=123456789:AAHk...          # Токен вашего хостинг-бота из @BotFather
REQUIRED_CHANNEL=@AstrixStudio       # Обязательный канал
CHANNEL_URL=https://t.me/AstrixStudio
ADMIN_IDS=123456789                  # Ваш Telegram ID для доступа к админ-панели
WEB_PORT=8080                        # Порт веб-панели
PUBLIC_URL=http://localhost:8080     # URL хостинга (или ваш домен / ngrok)
```

### 3. Запуск хостинга
```bash
python main.py
```

### 4. Использование
1. Откройте вашего бота в Telegram и отправьте `/start`.
2. Подпишитесь на канал [https://t.me/AstrixStudio](https://t.me/AstrixStudio) и нажмите **«✅ Проверить подписку»**.
3. Нажмите кнопку меню **«🚀 Мой хостинг»** — бот пришлет персональную защищенную ссылку на панель управления.
4. В панели создайте бота, укажите токен и нажмите **«Запустить»**!
